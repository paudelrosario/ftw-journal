# Journal — 10-07-2025 — Webscraping

## 1) What I learned
- Data moves in a path: Reality → Representation → Processing → Action, and the stages/lifecycle are Collection, Storage, Transformation, Serving, and Visualization/Decision.

- Data comes in shapes like Tabular, Hierarchical, Graph, Time Series, and Geospatial, commonly stored as CSV/SQL, JSON/XML, Neo4j/RDF, Parquet/Influx, and GeoJSON/Shapefile
- Data Formats: Pick formats based on use case not convenience.

- APIs are system-to-system, using endpoints, methods, parameters, headers/auth, and JSON responses.

- Webscraping. Ethics matters: collect and use data with consent, transparency, privacy, dignity, and responsibility

## 2) New vocabulary (define in your own words)
- **Endpoint:** The specific URL where a request is sent to access a defined resource in an API.
- **Columnar format:** A storage layout (e.g., Parquet/ORC) that stores data by columns for faster analytics and better compression.
